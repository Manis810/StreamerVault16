Privacy Policy

Last updated: November 2026

1. Information Collection and Use

The StreamerVault16 YouTube Automation Agent is a personal, single-user tool. It does not collect, store, or share any personal data from external users. The only data accessed is the authorization token required to upload videos to the channel owner's specific YouTube channel.

2. YouTube API Services

This application uses YouTube API Services. By using this application, you agree to be bound by the YouTube Terms of Service and the Google Privacy Policy.

This application only accesses the authorized user's YouTube channel data to facilitate video uploads. No data is stored on external servers, and all API interactions happen directly between the application and Google's servers.

3. Data Retention and Deletion

Because this is a local application, no user data is retained. Authentication tokens are stored locally on the device running the application and can be revoked at any time by the user via their Google Account security settings.

4. Contact

If you have any questions about this Privacy Policy, you can contact the developer at the email associated with the StreamerVault16 channel.
